# Welcome to the Sandbox 🧪

This organization serves as my personal laboratory for Proof of Concepts (PoCs), library explorations, and automation scripts. 

The goal of this space is to keep my main GitHub profile focused on polished, production-ready projects, while providing a dedicated environment to break things, test ideas, and experiment freely.

## 🔭 Current Focus
Here is what is currently being tested and developed in this lab:
*   **Python & JavaScript:** Automation scripts, API testing, and advanced concepts.
*   **Computer Vision:** Biomechanical analysis and video processing experiments.
*   **Infrastructure & Self-Hosting:** Proxmox configurations, Docker stacks, and homelab deployments.

## 📂 Repository Naming Convention
To keep the chaos organized, repositories in this organization follow a standard naming pattern:
*   `py-*` — Python scripts and library tests
*   `js-*` — JavaScript/TypeScript and Node.js experiments
*   `infra-*` — Infrastructure, containers, and server configurations
*   `poc-*` — General Proof of Concepts
