# ye-sandbox

Engineering sandbox and incubator for [@yegear1](https://github.com/yegear1).

Experiments, starters, infrastructure, and prototypes live here so the primary personal profile stays focused on released, production-ready work.

## Focus Areas

- **Agent-Driven Development (ADD)** — Frameworks, starters, and operational standards designed for collaborative engineering with AI coding agents ([`template-agent`](https://github.com/ye-sandbox/template-agent)).
- **Homelab Observability & IaC** — Compact observability pipelines and infrastructure setups ([`infra-victoria-logs`](https://github.com/ye-sandbox/infra-victoria-logs)).
- **Stack & Architecture Labs** — Isolated studies exploring language features, runtimes, and libraries ([`lab-ts-svelte`](https://github.com/ye-sandbox/lab-ts-svelte), [`lab-py-importlib`](https://github.com/ye-sandbox/lab-py-importlib)).

## Repository Taxonomy

Repositories in this organization follow a 4-category taxonomy in strict kebab-case:

| Category | Pattern | Purpose & Public Examples |
| :--- | :--- | :--- |
| **1. Multi-part Projects** | `[project]-[component]` | Modular product builds (`*-backend`, `*-web`, `*-extension`) |
| **2. Labs & PoCs** | `lab-[stack]-[topic]`<br>`poc-[topic]` | Isolated language/runtime tests ([`lab-ts-svelte`](https://github.com/ye-sandbox/lab-ts-svelte), [`lab-py-importlib`](https://github.com/ye-sandbox/lab-py-importlib)) and idea proofs of concept (`poc-*`) |
| **3. Infrastructure & Setup** | `infra-*`<br>`setup-*` | Persistent homelab & cloud services ([`infra-victoria-logs`](https://github.com/ye-sandbox/infra-victoria-logs)) and OS provisioning scripts (`setup-*`) |
| **4. AI, Agents & Starters** | `agent-*`<br>`template-*` | Autonomous agent implementations (`agent-*`) and ADD starters ([`template-agent`](https://github.com/ye-sandbox/template-agent)) |

When an experimental project stabilizes, it graduates to [yegear1](https://github.com/yegear1) or to a dedicated product organization.
