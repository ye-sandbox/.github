# ye-sandbox

Personal lab for [yegear1](https://github.com/yegear1). Experiments, templates, and homelab work live here so the main profile stays focused on finished projects.

## Current focus

Recent activity has been:

- **Agent-driven development** — starters and governance for AI coding agents (`template-*`), split by work type: greenfield, brownfield, blackbox reverse-engineering, and infra.
- **Homelab observability** — a small VictoriaLogs + Vector stack for Proxmox and Docker (`infra-*`), used by people and by agents during incident triage.

## Naming

| Prefix | Use |
| --- | --- |
| `template-*` | Agent-driven development starters and rules |
| `infra-*` | Homelab, Compose, Proxmox, service install |
| `py-*` | Python APIs, automation, library tests |
| `ts-*` | TypeScript / Svelte / front-end study |

When something stabilizes, it moves to [yegear1](https://github.com/yegear1) or a product repo.
